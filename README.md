Solmar Bay: Vice Run — an original open-world crime game set in the sun-soaked coastal city of Solmar Bay. Steal cars, outrun the police, and run five story jobs as getaway driver Mara Voss, with traffic, pedestrians, a wanted system, combat, taxi fares, hidden stashes and a save system.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Keyboard + mouse: WASD to move and drive, mouse to aim, click to shoot, E to steal or enter a car, Space for the handbrake, Esc to pause.
